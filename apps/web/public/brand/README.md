# Brand asset folder

Place league, team, and sponsor logo files here so they can be referenced by URL in the seed data.

Suggested structure:

- /brand/league/fli-golf/full-logo.svg
- /brand/league/fli-golf/mini-logo.svg
- /brand/league/fli-golf/mark.svg
- /brand/teams/skyhawks/full-logo.svg
- /brand/teams/skyhawks/mini-logo.svg
- /brand/teams/skyhawks/mark.svg
- /brand/teams/cypress/full-logo.svg
- /brand/teams/cypress/mini-logo.svg
- /brand/teams/cypress/mark.svg
- /brand/sponsors/prime-club/full-logo.svg
- /brand/sponsors/prime-club/mini-logo.svg

This makes the seed data easy to test before a real backend exists, and it avoids using the UI upload flow for local development.
