# FliHub Mobile

This Expo app is scaffolded around the same fantasy league lifecycle as the backend API.

## Flow

1. Home
2. FantasyLeaguesList
3. FantasyLeagueDetail
4. JoinFantasyLeague
5. LeagueMemberships
6. CreateFantasyTournament
7. DraftSetup
8. DraftRoom
9. FantasyStandings

## Verified backend constraints

- Fantasy league max participants: 6
- Default required approved participants: 5
- Owner counts toward total participant count
- Tournament creation requires enough approved participants

## Commands

```bash
npm install
npm run start
```
